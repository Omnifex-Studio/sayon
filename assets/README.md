# Sayon's logo

An interlocking S: rounded forms for approachable code, fitted together for the structure ownership checking gives. Its color is vermilion, `#DB5735`.

| File | Use |
| --- | --- |
| `logo.svg` | the logo, for pages and documents at any size |
| `logo-black.svg` (`#1F1A17`), `logo-white.svg` | where color is unavailable, and on dark photographs |
| `logo.png`, `icon-512.png`, `icon-128.png` | the logo at 1024, 512, and 128 pixels, for places that take only images |
| `sayon.ico` | the Windows icon of `sayon.exe`, the installer, and `.sayon` files, at 16 to 256 pixels |

The VS Code extension's icons are the 128 and 32 pixel images.

The artwork keeps a transparent margin on a square canvas: keep the square, and don't crop, stretch, recolor, or add gradients or shadows.
