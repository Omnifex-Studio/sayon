# Licenses and what Sayon's files hold

Sayon is licensed under the Apache License, Version 2.0 (`LICENSE`): its code, runtime, standard library, documentation, examples, templates, and images. This is the inventory of the material that is not Sayon's own: what a Sayon installation ships, what the programs Sayon builds carry into the world, and what Sayon uses without shipping it.

Sayon depends on no Rust packages but its own crates (`Cargo.lock` lists only `sayon-*`), so the material below is the whole of it.

## What an installation holds

`scripts/package.sh` and `scripts/package.ps1` make the downloads. They hold Sayon's `LICENSE`, and their `licenses` folder the texts of the licenses below, copied from the Rust toolchain that built them.

| Part | What is not Sayon's in it | License |
|---|---|---|
| `bin/sayon` | Rust's standard library (`core`, `alloc`, `std`, and `compiler_builtins`), compiled in | MIT or Apache-2.0, at the user's choice; parts of it hold Unicode's data, under the Unicode License v3 |
| | On Windows, Microsoft's C runtime (`libcmt`, `libucrt`, `libvcruntime`), linked statically (`.cargo/config.toml`), so that the tool needs no Visual C++ redistributable | Microsoft's terms for Visual Studio and its Build Tools, which cover distributing programs built with them; to be confirmed for the release |
| `lib/**/libsayon_runtime.a`, `lib/sayon_runtime.lib` | Rust's standard library, as above | MIT or Apache-2.0 |
| | The runtime's Unicode tables (`crates/runtime/src/unicode_tables.rs`), generated by `scripts/unicode_tables.py` from the Unicode Character Database | Unicode License v3 |
| | The built-in font of `standard/graphics` (`crates/runtime/src/font_table.rs`), generated by `scripts/font_table.py` from font8x8 by Daniel Hepper, after Marcel Sondaar's, from IBM's VGA fonts | Public domain |
| `lib/wasm32-wasip1/crt1-command.o`, `libc.a` | wasi-libc, the C library of WASI programs, as the Rust toolchain ships it; `NOTICE.txt` beside them says so | wasi-libc's [license](https://github.com/WebAssembly/wasi-libc/blob/main/LICENSE): Apache-2.0 with the LLVM exception, Apache-2.0, or MIT, with parts under their own permissive licenses |
| `stdlib`, `docs`, `examples`, `editors/vscode`, `assets` | Nothing | Apache-2.0, Sayon's |

## What compiled programs carry

A program Sayon builds holds the parts of Sayon's runtime it uses, under the Apache License 2.0, which asks whoever distributes the program to give its recipients a copy of that license; with the runtime come Rust's standard library (MIT or Apache-2.0), the Unicode tables (Unicode License v3), and, when it draws text in the built-in font, font8x8 (public domain). Each target adds its own:

| Target | What else a program holds or needs | License |
|---|---|---|
| `windows-x64` | Microsoft's C runtime, linked statically | Microsoft's terms, as above |
| `linux-x64` | Nothing linked in: it uses the system's C library (glibc) dynamically, and loads OpenSSL (`libssl.so.3`) and Xlib (`libX11.so.6`) from the system only when it uses TLS or a window | The system's |
| `wasi` | wasi-libc's startup code and the parts of its library the program uses, linked in | wasi-libc's, as above |
| `web` | The glue (`.js`) and page (`.html`), written from Sayon's templates (`crates/codegen/src/web`) | Apache-2.0, Sayon's |
| `android-x64`, `android-arm64` | The NDK's startup objects of Bionic (`crtbegin_so.o`, `crtend_so.o`) and LLVM's compiler runtime (`libclang_rt.builtins`), which the NDK's clang links in; the package's manifest, from Sayon's template; the system's `liblog`, `libandroid`, `libdl`, and `libm`, linked dynamically | The NDK's terms; Apache-2.0 with the LLVM exception for the compiler runtime, which asks no notice of programs |

Text drawn in one of the system's fonts is rendered from the font the user's system has; the font itself is never copied into a program or a package.

## What Sayon uses without shipping it

These are installed by the user, as `sayon doctor` and `sayon target setup` guide; Sayon never redistributes them.

| Tool | Used for | License |
|---|---|---|
| LLVM's clang and lld | Native, WASI, and web builds | Apache-2.0 with the LLVM exception |
| Visual Studio Build Tools and the Windows SDK | Native builds on Windows | Microsoft's terms |
| Android SDK: NDK, build tools, platform, `sdkmanager` | Android builds | The Android Software Development Kit License Agreement, which the user accepts when `sdkmanager` installs them |
| A JDK, 17 or newer | Signing Android packages (`apksigner`) | The JDK's, such as GPLv2 with the Classpath Exception for OpenJDK builds |
| The Rust toolchain | Building Sayon itself | MIT or Apache-2.0 |

## What only the tests use

The checks use wasmtime (Apache-2.0 with the LLVM exception), Node.js (MIT), Edge, Chrome, and Firefox (each under its own terms), Python (the PSF License), and the Android emulator and its system image (the Android SDK's terms). None of them is shipped. The tests' images and font are made by `scripts/graphics_data.py`, Sayon's own, under its license; the system fonts `tests/windows/fonts.sayon` finds are the system's, read where they are.
